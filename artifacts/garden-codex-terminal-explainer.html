Architecture explainer

Yes—Garden can run an Eve agent 1:1.

Garden’s official Eve mode starts the exact pinned project-local eve@0.27.6. Eve itself compiles the authored TypeScript, runs the agent loop, emits the protocol stream, and gives terminal tools a per-session sandbox.

What matters

Use --runtime eve for unmodified Eve semantics. Native Garden plus Codex remains a separate, narrower execution path.

Ownership boundary

● Official Eve owns

  • TypeScript compilation
  • Model and tool loop
  • Protocol and durability
  • Sandboxed terminal

○ Garden only owns

  • Pinned CLI validation
  • Child process group
  • Signals and shutdown
  • Operator output forwarding

Choose the semantic owner

One flag changes who runs the agent.

The 1:1 claim applies only when the official Eve runtime owns execution. Native mode deliberately keeps a smaller Go contract.

runtime eveOfficial Eve owns authored semantics. This is the 1:1 path.
runtime nativeGarden owns a scoped Go runner with OpenAI-compatible or Codex execution.
Implicit fallbackNever

Hard boundary

Codex support does not create Eve parity.

Native Codex mode is valuable when an Eve-shaped agent should inspect or edit a project. It remains separate from official Eve’s TypeScript and workflow runtime.

Action

Run the agent through its real Eve runtime.

Pin eve@0.27.6 in the project, install dependencies, then select official Eve mode. Garden supervises the process; Eve remains the semantic owner.
